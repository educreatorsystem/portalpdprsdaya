PAKEJ PWA PDPR SK TAMAN DAYA

1. Ekstrak ZIP ini.
2. Cipta repository GitHub (contoh: pdpr-sktd).
3. Upload SEMUA kandungan folder ini ke akar repository: index.html, pwa.js, sw.js, manifest.webmanifest, folder icons, folder vendor dan .nojekyll. Jangan upload ZIP sahaja.
4. Buka Settings > Pages > Build and deployment > Deploy from a branch.
5. Pilih branch main, folder / (root), kemudian Save.
6. Tunggu pautan GitHub Pages tersedia. Buka https://NAMA-AKAUN.github.io/pdpr-sktd/ (gantikan nama akaun dan repo).
7. Buka pautan terus dan pilih Pasang Aplikasi. iPhone/iPad: Safari > Kongsi > Tambah ke Skrin Utama.

GOOGLE SITES (PILIHAN)
Selepas GitHub Pages tersedia, Google Sites > Insert > Embed > By URL > tampal URL GitHub Pages. Untuk memasang aplikasi, buka URL GitHub Pages secara terus di pelayar, di luar embed.

PENTING
- Aplikasi memerlukan HTTPS (GitHub Pages menyediakannya). Membuka index.html dengan klik dua kali tidak mengaktifkan PWA.
- Kod login guru: JBA1077 (dikekalkan daripada kod asal).
- Semua pautan Google Sheet dan Apps Script sedia ada dikekalkan.
- Paparan asas boleh dibuka luar talian selepas lawatan pertama dengan internet. Nama murid, tugasan dan rekod tidak disimpan dalam cache kekal; internet diperlukan untuk memuat rekod dan menyimpan perubahan.
- Ikon Font Awesome, fon web, logo sekolah serta pautan video masih memerlukan internet. Ikon pemasangan aplikasi disertakan secara setempat.
- Sambungan backend asal menggunakan no-cors; respons kejayaan pelayan tidak dapat dibaca. Selepas simpan, tekan Muat Semula Data untuk mengesahkan. Penerbitan CSV Google mungkin mengambil masa untuk dikemas kini.
- Tiada perubahan data dibuat pada Google Sheet semasa penyediaan pakej.
- Kelas MATEMATIK / subjek 1 BESTARI dalam rekod SUMBER AIR masih perlu dibetulkan pada Sheet.

KEMAS KINI
Gantikan fail repository. Naikkan nama cache sw.js daripada v1 kepada v2 (dan seterusnya) apabila mengubah fail aplikasi. Aplikasi menawarkan butang Kemas Kini Aplikasi apabila versi baru tersedia; simpan kerja dahulu.


KEMAS KINI V2 — HANTAR SEKALI + LOGIN RUMUSAN
1. Gantikan fail GitHub dengan kandungan pakej ini.
2. Code.gs disertakan untuk ditampal ke Apps Script (bukan untuk dijalankan di GitHub). Jika backend 4.1 sebelum ini telah dipasang, kod backend tidak berubah.
3. Jika belum dipasang: gantikan Code.gs, jalankan semakTetapan(), kemudian Deploy > Manage deployments > Edit > New version > Deploy.
4. Buka aplikasi dan tekan Kemas Kini Aplikasi apabila muncul.
5. Kata laluan Rumusan: JBA1077. Login berasingan daripada Portal Guru; perlu login semula selepas refresh. Ini kunci paparan frontend, bukan kawalan akses pada CSV awam.
6. Semakan penghantaran menggunakan ID tugasan + kelas + nama murid. Tugasan berlainan bagi subjek yang sama masih boleh dihantar.
7. Backend menyekat rekod berganda dengan semakan dalam ScriptLock walaupun menggunakan peranti berbeza. Rekod berganda lama tidak dipadam.
8. Penanda permintaan sementara disimpan dalam pelayar selama 3 minit untuk menahan klik berulang semasa CSV belum dikemas kini. Status selesai hanya dipaparkan apabila rekod ditemui dalam CSV. Jika permintaan gagal, muat semula selepas 3 minit untuk mencuba lagi.
